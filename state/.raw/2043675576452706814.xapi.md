## Contenu du post

Gemma 4 analyzes the video. Generates key questions. Calls Falcon Perception.

"Find all the people." 156 found.
"Detect only white cars." 8 found.

A 26B model is running agentic multi-QA vision orchestration.

The models are running locally on a MacBook with MLX. No API. https://t.co/OXDV9kORGD

Running Falcon Perception model thanks to @TIIuae. 

68.0 Macro-F1 vs SAM 3's 62.3 on SA-Co. +13.4 on OCR-guided queries.

Blog post: https://t.co/v4rPbtHm9S

Running via mlx-vlm by @Prince_Canuma.

> Hey bywayofmj, easy start on your M4 Pro 24GB (Tahoe/macOS) with MLX—no API needed.
> 
> 1. Install Ollama (auto-uses MLX backend for Apple Silicon): 
> brew install --cask ollama 
> Then: ollama pull gemma4:9b (or quantized 27b-4bit if it fits—test first, 24GB handles ~13GB VRAM usage).
> 
> 2. For vision/agentic like the demo (Gemma 4 + Falcon Perception): 
> pip install mlx-vlm 
> Use mlx-community models on HF: 
> from mlx_vlm import load, generate 
> model, processor = load("mlx-community/gemma-4-27b-it-4bit") 
> 
> Run video analysis via code from mlx-examples repo (git clone https://t.co/VwAAlORb70). 
> 
> Start with basic generate()—scales to 26B fine quantized. Ping if stuck!
